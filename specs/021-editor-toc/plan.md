# Implementation Plan: Editor Table of Contents Panel

**Branch**: `worktree-feat+toc` | **Date**: 2026-06-13 | **Spec**: [spec.md](./spec.md)

## Summary

Add a collapsible left-side table of contents panel to the working document editor (`EditorPane.svelte`). The panel parses ATX markdown headings (H1-H6) from the live CodeMirror document string, renders them as an indented navigation list, and scrolls the editor cursor to the heading when clicked. The panel updates with a 300 ms debounce, respects all three themes via CSS custom properties, persists its open/closed state to `localStorage`, and hides automatically at narrow viewports.

## Technical Context

**Language/Version**: TypeScript 6.0, Svelte 5.55.2, SvelteKit 2.57

**Primary Dependencies**: CodeMirror 6 (already in project: `@codemirror/state`, `@codemirror/view`, `@codemirror/lang-markdown`), Svelte 5 runes, Tailwind CSS v4, `$app/environment` (browser guard)

**Storage**: `localStorage` key `lattice.editor.tocOpen` (boolean string). No spine API, migration, or database changes.

**Testing**: `cd surface && bun run check` for type correctness; unit tests for `parseToc.ts` via `bun run test:unit --project server` (pure function, no browser required); Playwright e2e smoke coverage via `bun run test:e2e` if feasible.

**Target Platform**: Browser SPA, all three themes (light / dark / sepia), tablet+ viewport (TOC hidden below 64 rem).

**Performance Goals**: TOC re-parse completes in under 5 ms for a 50-heading document. Debounce (300 ms) keeps TOC parsing off the keypress hot path.

**Constraints**: No new runtime dependency. No spine changes. No new full-screen layout shift. WCAG 2.2 AA for keyboard operation, focus visibility, and contrast. Consistent with existing editor CSS token usage.

**Scale/Scope**: Two new Surface files (`parseToc.ts`, `EditorToc.svelte`) plus modifications to `EditorPane.svelte`. No workbench-level or routing changes.

## Phase 1: Design

### Data Model

**TocEntry** (TypeScript interface in `parseToc.ts`):

```typescript
export interface TocEntry {
  level: number;       // 1–6
  text: string;        // heading text without hashes
  lineNumber: number;  // 1-based line number in the document
}
```

No persistence. Derived client-side from the live document string.

### Component Interface

**`parseToc(docText: string): TocEntry[]`**

```typescript
// surface/src/lib/editor/parseToc.ts
const HEADING_RE = /^(#{1,6})\s+(.+)/;

export function parseToc(docText: string): TocEntry[] {
  const entries: TocEntry[] = [];
  const lines = docText.split('\n');
  for (let i = 0; i < lines.length; i++) {
    const m = HEADING_RE.exec(lines[i]);
    if (m) entries.push({ level: m[1].length, text: m[2].trimEnd(), lineNumber: i + 1 });
  }
  return entries;
}
```

**`EditorToc.svelte` Props**:

```typescript
const { entries, onNavigate }: {
  entries: TocEntry[];
  onNavigate: (lineNumber: number) => void;
} = $props();
```

**`EditorPane.svelte` New State**:

```typescript
let docText = $state('');               // updated by update listener
let debouncedText = $state('');         // 300 ms debounced from docText
let tocOpen = $state(true);             // initialized from localStorage

const tocEntries = $derived(parseToc(debouncedText));
```

**Navigation callback** (in EditorPane, passed to EditorToc):

```typescript
function navigateToLine(lineNumber: number) {
  if (!view) return;
  const line = view.state.doc.line(lineNumber);
  view.dispatch({
    selection: EditorSelection.cursor(line.from),
    effects: EditorView.scrollIntoView(line.from, { y: 'start', yMargin: 16 })
  });
  view.focus();
}
```
